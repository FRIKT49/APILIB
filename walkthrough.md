## 🚦 Инструкция по запуску

1. Запустите локальный веб-сервер в корне проекта:
   ```bash
   python -m http.server 8080
   ```
2. Откройте в браузере: `http://localhost:8080`
3. Укажите ваши ключи из Firebase Console в файле `js/firebase.js` в объекте `firebaseConfig`.
4. Зарегистрируйтесь на странице `register.html` и назначьте роль `admin` в Firebase Console, чтобы протестировать админ-панель и загрузку 18 демо-API в один клик.
